# NeuroOncoTrack-AI Dijital Kartvizit

GitHub Pages için statik tek sayfalık site.

## Yayına alma
1. Bu klasörün içeriğini GitHub repository kök dizinine yükleyin.
2. GitHub > Settings > Pages bölümünden `Deploy from a branch` seçin.
3. `main` ve `/ (root)` seçerek kaydedin.

## Profil fotoğrafları
Aşağıdaki dosyaları eklediğinizde avatarlar otomatik fotoğrafa dönüşür:
- `assets/team/mert.webp`
- `assets/team/yusufcan.webp`
- `assets/team/hakan.webp`
- `assets/team/zeynep.webp`

Fotoğraf yoksa baş harf avatarı görünür.

## QR kodlar
`assets/qr/` klasöründeki QR kodlar kişi bilgilerini vCard formatında içerir. QR butonu dosya indirmez; kod ekranda açılır ve başka bir telefonla taranabilir.
